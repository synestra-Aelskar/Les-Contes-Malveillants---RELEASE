# Les Contes Malveillants

Téléchargez le zip `LesContesMalveillants-<version>.zip` de la dernière Release (pas l'archive « Source code »).

## Installation

1. **Le module en jeu** : copiez le dossier `LCMCoreAddon` dans `World of Warcraft\_retail_\Interface\AddOns\`.
2. **L'application** : placez `Les Contes Malveillants v3.0.exe` où vous voulez, puis lancez-la avec WoW ouvert.
3. Si l'ancien addon `LesContesMalveillants` est encore dans votre dossier AddOns, supprimez-le : l'application le remplace.

En jeu, faites `/reload` après avoir installé ou mis à jour `LCMCoreAddon`.
